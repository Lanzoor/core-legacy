Anti-JPA Project

The Anti-JPA Project was an exposal pointing out the issues within the Japanese Academy server in detail, created by Lanzoor.

Lanzoor started working on this project at around March 15th. The project was revealed to the public on March 27th with a countdown timer, but was quickly moved to legacy after backlash from the moderation team.
